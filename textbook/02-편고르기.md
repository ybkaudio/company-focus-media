# 2장. 편 고르기 (원고 대기열 채우기)

## 언제
- 매일 00:00 스캔이 원고 대기열이 모자라다고 할 때, 또는 사용자가 인물·회사를 정해 줄 때.

## 들어오는 것
- 공동 구글 문서(16w0KTBVATdwjiNuUlaoKIVjDcRc0CmgvAKbI2xlIzc0)의 탭 목록. 원고 대기열 = `표지 제목:`이 빈 탭.
- `publisher/schedule.json`(이미 렌더·게시된 편), Notion '인스타 게시 기록'.

## 순서
1. 대기열 수를 셈: [기업인] `[기업인]` 탭 중 `표지 제목:` 빈 탭 / [AI] `[AI]` 탭 중 빈 탭. (11/23)
2. [기업인] 8편 미만이면 모자란 만큼 새 편을 고름(하루 2편 게시 기준, 11/26). [AI] 5편 미만이면 모자란 만큼. (11/23)
3. 후보 고르기: 이미 탭·schedule.json·게시 기록에 있는 인물·회사는 뺌. 사용자가 정한 인물이 있으면 그것부터.
4. [기업인] 여러 회사를 만든 사람은 회사마다 편을 나눔. 단 여러 회사를 세우고 투자한 인물은 '여정' 한 편으로 묶고, 짧게 다룬 회사는 그 회사를 이끈 인물 편을 바로 다음에 둠. (11/13 피터 틸 → 알렉스 카프)
5. [기업인] 같은 회사·인맥 편은 묶음으로 이어서 고름(설명란 🔗 줄, 8장). (11/10)
6. 화제 편(지금 뉴스에 오른 인물·회사)이면 표시해 둠 → 4장 '위기' 장 규칙. (11/12 젠슨 황)
7. 편마다 stem을 정함(`NN-slug`, 예: `41-peter-thiel`) → `python3 tools/step.py start <stem> "인물 · 회사" --account kiupin|ai`.

## 통과 기준
- [ ] 이미 다룬 인물·회사가 아님(탭·schedule.json·게시 기록 확인)
- [ ] 진행표가 생김(`episodes/<stem>.steps.json`)

## 넘기는 것 → 3장
- stem, 인물·회사, 화제 편 여부.
