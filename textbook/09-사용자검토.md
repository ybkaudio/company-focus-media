# 9장. 사용자 검토 (사용자의 단계, Claude는 기다리며 감지만)

## 사용자가 하는 것
- 탭을 읽고 글·사진을 고침. 사진을 바꿀 땐 `사진 설명:` 줄을 지워 둠. (11/23)
- 표지 장 `표지 제목:` 줄에 제목을 씀 = **최종 합격**. 렌더 결과는 보지 않음. (11/23 "제목이 입력된다면 최종 합격")

## Claude가 하는 것
- 기다리는 동안 묻지 않음. 이 편에 대한 질문이 생기면 13장 기준으로만.
- 원고를 손볼 일이 생기면 먼저 `read_doc` → `python3 publisher/photo_fp.py <결과 파일>`로 사용자 교체를 확인(교체 사진은 절대 바꾸지 않음). (11/26)
- 사용자가 탭 본문을 고치면 고친 곳만 JSON에 반영(렌더 때 doc2episode.py가 가져옴). 규칙이 바뀌는 수정이면 12장 개정.
- 사용자가 "제목 적었어"라고 하면 00시를 기다리지 않고 그 턴에 10장을 시작함(제목 찬 탭 중 schedule.json에 없는 것 전부, 문서 앞 순). (11/25)

## 규칙
- 사용자가 직접 올린 사진은 절대 바꾸지 않음. 사진과 글이 안 맞거나 글이 부족하면 사진이 아니라 글(본문·사진 설명)을 고침. 올린 순서 그대로(첫 사진 = 표지). "N번은 M장 스티커로"도 그대로. (11/11 머스크·PayPal "순서 바꾸지 마", 11/25)
- 사용자가 직접 쓴 문구·표기는 그대로(사실과 다른 낱말만 6장 규칙). (11/11 웨인)
- 렌더 시작 조건은 `표지 제목:`을 사용자가 직접 쓴 것 하나뿐. 후보 ①②③은 조건 아님. (11/25)
