- AI 생성 의심 사진: 사용자가 올린 사진도 글자 깨짐·인원수 불일치·워터마크(History Hub 등)를 보고, 의심되면 교체를 추천함. #13 표지(세 명·"Mconald's")와 05장이 그랬고, 사용자가 실사진으로 바꿈. 사람 없는 배경 사진(#14 AWS)은 그대로 둬도 됨.
- 같은 회사의 다른 창업자 편(예: #05 바워만 ↔ #15 필 나이트, #01 잡스 ↔ #19 웨인)은 카드에서도 연결함. 사용자: "사람들이 헷갈릴 수 있을 것 같아". 방법: 표지 제목에 관계(예: "코치의 제자였던…"), 첫 언급 장 본문에 "(#NN 주인공)", 캡션 첫 줄 아래 "Nike를 세운 두 사람 중…", 🔗 줄. 이미 게시된 앞 편 캡션은 사용자가 인스타 앱에서 직접 한 줄 추가(추천).
- 사용자가 사진을 보낼 때 "N번 사진은 M페이지 스티커로" 식으로 지시함. N은 사용자가 보낸 순서, M은 장 순서(01=표지).

- (11/09 #17) 사용자가 로고 사진을 따로 주면 로고는 표지 스티커로만 쓰고, 마무리 장 배경은 로고 대신 인물 사진을 씀(사용자가 지정한 사진).

- (11/09) 사진을 어둡게 누르거나 흐리게 하지 않음. 원본 밝기·선명도 유지, 가독성은 그라데이션으로만(사용자: "너무 어둡고 흐리다"). 워터마크는 크롭.

- (11/10 #23) 사용자가 한 묶음으로 보낸 사진은 01 표지부터 순서대로임(첫 사진=표지). 장난스러운 제스처(가운뎃손가락 등)도 사용자가 고르면 크롭·제외하지 않음("재밌는데").

**Why:** 사실을 다루는 계정이라 가짜 사진·혼동은 댓글로 바로 지적받음.
**How to apply:** 사진 배치 때 매번 점검하고, 새 원고 쓸 때 같은 회사 기존 편이 있으면 처음부터 연결 줄을 넣음. [[kiup-wongo-department]] [[kiup-family-name-check]]

- (11/11 #15 사용자) 로고 하나뿐인 사진을 배경으로 쓸 때는 로고를 정중앙에 둔다(앞으로 모든 편).
- (11/11 #24 사용자 강한 지적) 사진은 사용자가 올린 순서 그대로 쓴다. 내용이 안 맞아 보여도 순서를 바꾸지 말 것("어디서 지맘대로 순서를 바꾸고 있어"). 걱정되면 그대로 넣고 한 줄로만 알림.
