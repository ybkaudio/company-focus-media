- 2026-11-13 사용자: "피터 틸편 사진을 네가 직접 구해서 렌더링해서 보여줘봐" → 위키미디어 공용(CC/PD)에서 17장 골라 렌더(d668333). 출처는 episodes/<편>/photos/SOURCES.txt, 미리보기는 production/thiel-overview-v1.png. 편성표엔 넣지 않음.
- 방법: Commons API 검색(generator=search, namespace 6)이 429를 자주 냄 → 검색 사이 15초 쉬고 재시도. 내려받기는 Special:FilePath/<파일>?width=1600(일부 파일은 429, 다른 파일로 대체).
- 한계: 1990~2000년대 초 인물 사진은 자유 이용 사진이 거의 없어 시기가 안 맞는 사진을 씀. 사용자에게 알리고 출처 표기 한 줄을 추천함.

**Why:** 사용자가 사진 찾는 수고를 넘기려고 시험해 봄.
**How to apply:** 사용자가 직접 구하라고 한 편에만 씀. 사용자가 사진을 올리면 그 사진이 우선. [[production-publishing-dept]] [[kiup-photo-and-link-rules]]
