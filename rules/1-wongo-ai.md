# ① 원고 규칙: AI기업집중탐구만의 것

공통 규칙 [1-wongo-common.md](1-wongo-common.md)과 같이 읽음. 디자인·업로드는 이 저장소 범위 밖. (11/23, 옛 원문 archive/ai-series-style-guide.md)

| 기업집중탐구 | AI기업집중탐구 |
|---|---|
| 주인공 = 창업자 한 명 | 주인공 = 회사. 인물은 장마다 "결정한 사람" 한 명으로 분명히 |
| 질문: 왜 이 사람에게서 시작돼 어떤 능력으로 커졌나 | 무엇을 보고 시작돼 어떤 판단들로 지금 자리에 왔나 |
| 끝 = 떠날 때(stats: 떠날 때 가치 + 기간) | 끝 = '지금' 장(stats: ① 최근 회사 가치, 기준·연월 ② 설립부터 지금까지) |
| 마무리 3줄 = 인물의 가장 대단한 면모 | 마무리 3줄 = 회사가 지금 자리에 온 이유(판단·구조)를 구체 사건과 |
| 장 위 '연도 · 나이' | '연도 · 설립 N년차'(필요하면 '2023.03') |

- 장 이름은 공통 목록에서 떠날 때·그 뒤·매각 대신 '지금'. (11/23)
- 다른 AI 기업 편과 얽히면 카드 안에서 "(○○ 편에서 이어짐)". (11/23)
- 미래 전망은 쓰지 않음. 경영진이 공식으로 밝힌 계획만 "밝혔다". (11/23)
- 원고는 같은 공동 구글 문서 `[AI] 회사명` 탭. 점검·게시 시각: 08:43·18:43 점검, 10:00·20:00 게시. (11/23)
