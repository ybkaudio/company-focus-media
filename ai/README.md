# ai/ — AI기업집중탐구(@aicompany.focus) 업로드 폴더

기업집중탐구 파일(posts/, publisher/, episodes/)과 따로 씀. AI 쪽 Claude만 고침.

- `posts/NN-slug/01.jpg…` + `caption.txt`: 렌더·점검을 통과한 편. Aside가 raw 주소로 내려받아 Business Suite에 예약함.
- `upcoming.txt`: 앞으로 올라갈 편 목록. Aside 루틴(매일 01·05·09·13·17·21시)이 읽음.
- `schedule.json`: 슬롯 기록(02·06·10·14·18·22시 KST).
- 셋 다 `/mnt/project-files/ai-pack/tools/publish_ai.py`가 씀. 손으로 고치지 않음. 규칙: rules/8-ai-upload.md.
